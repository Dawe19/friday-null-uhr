# Friday Null Uhr

Weekly Spotify discovery for new French and US rap. The Docker container schedules itself for Friday at 03:00 Europe/Berlin and appends every eligible track it finds from the previous seven days.

See [container/README.md](container/README.md) for GitHub-based server setup.

Spotify credentials, playlist IDs, and personalized artist lists belong in ignored local configuration files; do not commit them.
